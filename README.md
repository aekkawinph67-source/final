# คอร์สแวร์ความจริงเสริมเพื่อการเรียนรู้ (ว201121)

บทเรียนคอมพิวเตอร์ช่วยสอน (CAI) เรื่องความจริงเสริม (AR) สำหรับนักเรียนชั้น ม.4 โรงเรียนมัธยมวานรนิวาส พร้อมระบบหลังบ้านบน Supabase (คะแนน ความก้าวหน้า รูปโปรไฟล์ งานที่ส่ง และสื่อของผู้สอน)

> สถานะ: **ยังไม่ได้ทดสอบกับโปรเจกต์ Supabase จริง** ตรวจแล้วเฉพาะไวยากรณ์ JavaScript และจำนวนข้อสอบ

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `setup.sql` | สร้างตาราง นโยบาย RLS trigger มุมมอง results และ Storage 3 ที่ รันครั้งเดียวใน SQL Editor |
| `courseware.html` | หน้าเว็บไฟล์เดียว (ผู้เรียนและผู้สอน) |
| `guide.md` | ข้อสมมติ คู่มือติดตั้ง 10 ขั้น แบบทดสอบระบบ 15 ข้อ และรายการที่ผู้สอนต้องตรวจเอง |
| `README.md` | ไฟล์นี้ |

## เริ่มต้นอย่างย่อ
1. สร้างโปรเจกต์ที่ supabase.com และ **ปิด Confirm email** (Authentication > Sign In / Providers > Email)
2. วาง `setup.sql` ทั้งไฟล์ใน SQL Editor แล้ว Run
3. สร้างบัญชีครูที่ Authentication > Users (ติ๊ก Auto Confirm User) แล้วรันคำสั่งตั้งผู้สอนท้ายไฟล์ (เปิดคอมเมนต์ แก้อีเมล)
4. นำเข้ารายชื่อนักเรียนจริงเป็น CSV ที่ Table Editor > students (หัวคอลัมน์ `id,title,first_name,last_name,section`) และลบแถวตัวอย่าง 6 แถว
5. ใส่ `SUPABASE_URL` และ `SUPABASE_ANON_KEY` ที่ต้นสคริปต์ใน `courseware.html` (**ห้ามใส่คีย์ลับของผู้ดูแลระบบ**)
6. นำไฟล์ขึ้นเว็บที่เปิดผ่าน https (โหมด AR ต้องใช้ https) แล้วทดสอบตามตาราง 15 ข้อใน `guide.md`

รายละเอียดทีละขั้นอยู่ใน `guide.md` ตอนที่ 4

## การใช้งาน
- **นักเรียน:** สมัครด้วยรหัสประจำตัว 11 หลักและรหัสผ่านที่ตั้งเอง (ระบบสร้างอีเมล `<รหัส>@mwn.ac.th` ให้เอง) → ก่อนเรียน → หน่วย 1–5 → หลังเรียน → สรุปผล → สื่อเพิ่มเติม → โปรไฟล์ → ส่งงาน
- **ครู:** เข้าด้วยอีเมล ดูผลรายคน ตรวจและให้คะแนนงาน จัดการสื่อ ส่งออก CSV (เปิดใน Excel ภาษาไทยได้)

## ค่าที่ปรับได้
- `EMAIL_DOMAIN` และข้อความรายวิชา (`COURSE`) ที่ต้นสคริปต์ใน `courseware.html`
- รูปแบบรหัสนักเรียน 11 หลักเป็นข้อสมมติ หากไม่ตรง ต้องแก้ regex `^[0-9]{11}$` ใน `setup.sql` และ `^\d{11}$` ใน `courseware.html`
- การสลับข้อสอบ: เลขท้ายคี่ = ก่อนเรียนชุด B หลังเรียนชุด A, เลขท้ายคู่ = ก่อนเรียนชุด A หลังเรียนชุด B

## ความปลอดภัยโดยสรุป
- เปิด RLS ทุกตาราง และ revoke สิทธิ์จาก anon; ผู้เรียนเห็นเฉพาะข้อมูลของตน
- ผู้เรียนแก้ `score` และ `teacher_comment` ใน submissions ไม่ได้ (สิทธิ์ระดับคอลัมน์ + นโยบาย INSERT + ไม่มีนโยบาย UPDATE ของผู้เรียน)
- Storage เป็น private ทั้ง 3 ที่ จำกัดชนิดและขนาดไฟล์ เปิดไฟล์ด้วย signed URL เท่านั้น
- ข้อความจากฐานข้อมูลถูก escape ก่อนแสดง ลิงก์รับเฉพาะ http/https และเปิดด้วย `rel="noopener noreferrer"`
- ไฟล์ HTML ใส่เฉพาะ URL และ anon key เท่านั้น

## ข้อจำกัดที่ทราบ
- ไม่มีส่วนเสริม A-Frame, AR.js, MindAR (ข้ามโดยตั้งใจ เพื่อไม่ให้เดา API)
- โมเดลตัวอย่างในหน่วย 4 โหลดจาก modelviewer.dev ซึ่งอาจเปลี่ยนลิงก์ได้
- โหมด AR ขึ้นกับอุปกรณ์และเบราว์เซอร์ของนักเรียน ควรทดสอบกับเครื่องจริง
- ผู้เรียนเปลี่ยนรหัสผ่านเองในหน้านี้ไม่ได้ ครูรีเซ็ตที่ Authentication > Users
- เนื้อหา สูตร E1/E2 และเฉลยข้อสอบ ควรตรวจกับต้นฉบับก่อนใช้จริง (ดู `guide.md` ตอนที่ 6)
